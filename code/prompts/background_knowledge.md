### 深远海船舶作业的设备介绍

| 类别 | 设备 | 功能 | 相关数据 |
|----------|---------|----------|--------------|
| 甲板机械 | A架 | 负责深海设备（如征服者）的起吊、发射和回收 | A架左/右角度、1/2号启动柜电流、主液压泵电流 |
|  | 绞车 | 用于牵引、起吊和张紧缆绳，辅助深海设备作业 | 绞车A/B/C放缆长度/速度/张力、科学变频绞车电流 |
|  | 折臂吊车 | 主要用于小艇的下放和回收，具备灵活操作能力 | 液压电流、电压等 |
| 推进系统 | 发电机组 | 提供全船电力，包括四台柴油发电机和一台应急柴油发电机 | 有功功率、转速、燃油消耗率 |
|  | 主推进器 | 提供主要推进动力，使船舶前进 | 推进变频器功率允许/反馈 |
|  | 艏侧推 | 主要用于精确调整船头位置，辅助停靠或DP定位 | 主开关电流、螺旋桨螺距命令/反馈、功率反馈/允许 |
|  | 可伸缩推 | 360°旋转，提高船舶在不同海况下的操控能力 | 主开关电流、螺距命令/反馈、方位命令/反馈、功率反馈/允许 |
|  | 舵桨 | 由推进器驱动，主要用于改变航向 | 左/右舵桨主开关电流、转速/方向命令/反馈、转舵A/B电流 |

### 深远海船舶作业的整体流程
| 阶段 | 关键动作 | 判断规则 | 描述 |
|----------|----------|--------------|----------|
| 1. 设备下放阶段 | ON DP（动力定位系统启动）  | 数值从0增加（取增加）                        | 依靠主推进器、艏侧推、可伸缩推保持船舶稳定，避免漂移。 |
|  | A架开机 | 电流值从error变为0（取0） | 启动A架系统，确保起吊设备正常运作。 |
|  | 折臂吊车开机               | 数值从0增加（取增加）                        | 准备小艇的下放或回收。                                 |
|  | 小艇检查完毕               | 数值增加（回落前的最后一个值）               | 确保小艇及人员安全，进入下一步。                       |
|  | 小艇入水                   | 数值增加（回落前的最后一个值）               | 折臂吊车放下小艇，进入作业区域。                       |
|                 | 征服者起吊                 | 电流从稳定值（50多），取高于50的点           | 利用A架和绞车系统将征服者从甲板上起吊。                |
|                 | A架摆出                    | 征服者起吊后，电流到达峰值                   |                                                        |
|  | 征服者入水                 | 缆绳解除的时间点往前推一分钟                 | 通过A架摆动及绞车放缆控制，使征服者缓慢进入海中。      |
| | 缆绳解除                   | 电流从高值回落至稳定值（50多），取50         | 确认征服者已安全入水并解除相关缆绳，设备进入作业模式。 |
| | A架摆回                    | 征服者入水后，电流重新增加到峰值（最大值点） | A架恢复至收纳状态。                                    |
|  | 小艇落座 | 数值增加（回落前的最后一个值） | 折臂吊车调整小艇位置，为潜水或辅助作业做准备。 |
|  | 折臂吊车关机               | 数值归零（取0）                              | 关闭折臂吊车系统。                                     |
|                 | A架关机                    | 电流值变为error（取error）                   | 关闭A架系统，避免不必要的能耗。                        |
|  | OFF DP（动力定位系统关闭） | 数值归零（取0）                              | 结束DP模式，恢复正常推进状态，准备返航或继续其他任务。 |
| 2. 深海作业执行 | 征服者执行作业 | - | 设备进入自主作业模式，如海底探测、样本采集等。 |
| 3. 设备回收阶段 | A架开机                    | 电流值从error变为0（取0）                    | 启动A架系统，确保起吊设备正常运作。                    |
|  | 折臂吊车开机 | 数值从0增加（取增加） | 准备小艇的下放或回收。 |
|  | A架摆出 | 征服者起吊后，电流到达峰值 |  |
|  | 小艇检查完毕 | 数值增加（回落前的最后一个值） | 确保小艇及人员安全，进入下一步。 |
|  | 小艇入水 | 数值增加（回落前的最后一个值） | 折臂吊车放下小艇，进入作业区域。 |
|  | 缆绳挂妥 | 征服者出水往前推一分钟 | 小艇协助重新挂妥征服者的缆绳，确保稳定回收。 |
|  | 征服者出水                 | 电流峰值（取峰值）                           | 通过绞车系统和A架配合，将征服者缓慢上升至水面。        |
|  | 小艇落座 | 数值增加（回落前的最后一个值） | 折臂吊车调整小艇位置，为潜水或辅助作业做准备。 |
|  | 折臂吊车关机 | 数值归零（取0） | 关闭折臂吊车系统。 |
|  | 征服者落座 | 电流从高值回落至稳定值（50多），取50 | 征服者成功回收至甲板。 |
|  | A架关机                    | 电流值变为error（取error）                   | 关闭A架系统，避免不必要的能耗。                        |
